# Personal Expenses Tracker

Веб-приложение для отслеживания личных расходов, построенное на Flask с использованием SQLAlchemy.

## Описание

Personal Expenses Tracker — это полнофункциональное веб-приложение, которое позволяет пользователям:
- Регистрироваться и входить в систему
- Добавлять, просматривать, редактировать и удалять свои расходы
- Категоризировать расходы
- Отслеживать способы оплаты
- Просматривать статистику расходов за последний месяц
- Добавлять комментарии к каждому расходу

### CRUD

#### Пользователи:
- `POST /api/users` - Создать пользователя
- `GET /api/users/<id>` - Получить информацию о пользователе
- `PUT /api/users/<id>` - Обновить пользователя
- `DELETE /api/users/<id>` - Удалить пользователя

#### Расходы:
- `POST /api/expenses` - Создать расход
- `GET /api/expenses/<id>` - Получить расход
- `PUT /api/expenses/<id>` - Обновить расход
- `DELETE /api/expenses/<id>` - Удалить расход
- `GET /api/users/<id>/expenses` - Получить все расходы пользователя

## Установка

### Требования
- Python 3.7+
- pip

### Шаги установки

1. **Клонируйте репозиторий**:
```bash
git clone https://github.com/DeadlyM0uth/personal-expenses-tracker.git
cd personal-expenses-tracker
```

2. **Создайте виртуальное окружение**:
```bash
python -m venv .venv
```

3. **Активируйте виртуальное окружение**:
   - Windows:
     ```bash
     .venv\Scripts\activate
     ```
   - macOS/Linux:
     ```bash
     source .venv/bin/activate
     ```

4. **Установите зависимости**:
```bash
pip install -r requirments.txt
```

## Запуск приложения

### Режим разработки

Запустите приложение с помощью Flask:

```bash
flask --app ./main.py run
```

Приложение будет доступно по адресу: `http://127.0.0.1:5000`

## Модели базы данных

### User (Пользователь)
- `id` - Уникальный идентификатор
- `username` - Имя пользователя (уникальное)
- `password_hash` - Хешированный пароль

### Expense (Расход)
- `id` - Уникальный идентификатор
- `amount` - Сумма расхода
- `category` - Категория (автоматически в нижнем регистре)
- `date` - Дата и время расхода
- `comment` - Комментарий (опционально)
- `payment_method` - Способ оплаты (опционально)
- `user_id` - ID пользователя (внешний ключ)


## Миграции базы данных

Приложение использует Flask-Migrate для управления схемой базы данных.

**Создать новую миграцию**:
```bash
flask --app ./main.py db migrate -m "Описание изменений"
```

**Применить миграции**:
```bash
flask --app ./main.py db upgrade
```

**Откатить миграцию**:
```bash
flask --app ./main.py db downgrade
```
